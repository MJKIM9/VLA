## 1. 이번 기간 요약

VLA(Vision-Language-Action) 추론 파이프라인을 개선하고 하이브리드 데모 방식을 도입했다. state 입력을 2D xy 오정렬 벡터에서 3D xyz 오정렬 벡터로 확장하고, 절대 관절각 대신 델타 관절각(delta action)으로 학습 및 추론 방식을 전환했다. 또한 VLA 추론 전 6단계 사전 티칭 동작을 수행하는 하이브리드 구조를 구현하고, 관절 공간 보간 이동을 카르테시안 직선 이동(moveL)으로 교체했다.

---

## 2. 개발 내용 상세

### 원리

**Delta Action 학습 및 추론**

기존에는 모델이 절대 관절각을 출력했으나, 이번 기간에 델타 관절각(GELLO_t - UR_t) 방식으로 전환했다. 텔레오퍼레이션 수집 시 `delta_action = action_snap - obs_snap["joint_positions"]`로 기록하고, 추론 시 `action_np = q_current + delta_np`로 실행한다. 델타 방식은 시작 자세에 대한 의존성을 줄이고, 상대적 움직임을 학습하므로 위치 일반화에 유리하다.

**State 입력 확장: xy → xyz 오정렬 벡터**

손목 카메라로 빨간 그리퍼 핑거와 노란 작업 대상물을 HSV 색상 검출로 찾고, RealSense 깊이 카메라의 `pixel_to_3d()`로 3D 좌표를 구한 뒤 두 물체의 차이 벡터 `red_3d - yellow_3d`를 state에 포함한다. 기존 2D(x, y)에서 3D(x, y, z)로 확장해 STATE_DIM이 16→17차원이 됐다. 검출 실패 시 `np.zeros(3)`을 반환해 학습 안정성을 유지한다.

**하이브리드 데모 구조**

VLA 추론만으로는 초기 자세 획득이 불안정한 문제를 해결하기 위해 사전 티칭 동작과 VLA 추론을 결합한 하이브리드 방식을 도입했다. 6단계 사전 동작(그리퍼 열기, 케이블 파지 전 자세, 파지 자세, 그리퍼 닫기, 파지 후 자세, 홈 복귀)을 먼저 수행한 뒤 VLA 추론을 시작한다. 각 단계는 moveL(카르테시안 직선 이동)로 실행하며, 중간에 정지 요청이 들어오면 watchdog 스레드가 stopL을 호출한다.

**카르테시안 직선 이동(moveL) 전환**

기존 사전 티칭 동작은 관절 공간 보간(`move_to`)으로 구현했으나, 케이블 파지 경로에서 곡선 경로 문제가 발생했다. `left_robot.robot.moveL(pose_rad, speed, accel)` API를 사용하는 카르테시안 직선 이동으로 교체했다. moveL 호출 전 매번 `reuploadScript()`로 RTDE 스크립트를 재시작해 servoJ 잔류 상태로 인한 "another thread controlling" 오류를 방지한다. ZYX 오일러 각도(degree)를 UR rotation vector(radian)로 변환하는 `_euler_zyx_deg_to_rot_vec()` 함수를 별도 구현했다.

**Temporal Ensembling 및 스무딩 시도 및 롤백**

청크 경계에서 발생하는 튀는 현상을 줄이기 위해 Temporal Ensembling(coeff=0.01)과 dx/dy 이동평균 스무딩(5프레임, 감쇠 0.4)을 적용했으나, 오히려 동작 품질이 저하되어 모두 롤백했다.

### 순서 및 단계

**데이터 수집 흐름 (launch_yaml.py)**

1. YAML에서 로봇, GELLO, 그리퍼, 카메라, 데이터셋 설정 로드
2. ZMQ 서버를 통해 RobotEnv 생성, 2π 오프셋 자동 보정
3. ControlPanel UI 실행, 텔레오퍼레이션 토글 이벤트 대기
4. 텔레오퍼레이션 활성 시: GELLO에서 action 읽기 → 카메라 캡처 → `(obs_T, action_T, imgs)` 큐에 푸시 → env.step(action) 실행
5. `record_worker` 스레드: 큐에서 꺼내 align_xyz 계산 → delta action = action - joint_pos → `recorder.add_frame()` 호출
6. 에피소드 저장: LeRobot 포맷으로 HDF5 저장

**하이브리드 데모 흐름 (vla_demo_fn)**

1. ACT 정책 lazy-load (첫 실행 시만)
2. servoStop → reuploadScript로 servoJ 스크립트 종료
3. 6단계 사전 티칭: gripper open → moveL(파지 전) → moveL(파지) → gripper close → moveL(파지 후) → 홈 복귀(관절 공간)
4. run_inference() 호출: 카메라 버퍼 준비 대기 → chunk 추론 → delta action 실행 → 다음 chunk 비동기 prefetch

**VLA 추론 루프 (run_inference)**

1. `_CameraBuffer` 백그라운드 스레드로 카메라 프레임 지속 갱신
2. 첫 chunk 동기 추론 (워밍업)
3. 루프: 카메라 버퍼에서 즉시 읽기 → chunk 0번째 step에서 다음 chunk 비동기 추론 시작 → delta_np 꺼내기 → action = q_current + delta_np → servoJ 실행
4. chunk 소진 시 다음 chunk 결과 교체
