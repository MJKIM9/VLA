# 진행 보고 (발표용)

* 기간: 26.07.29 - 26.07.29

* 이번 기간 개발 내용
   * 그리퍼 기준값 체크포인트별 조건부 적용 - v21(그리퍼 실제 값으로 학습)에서만 추론 시 그리퍼 목표값을 실제 명령값 추적 기준으로 계산, v19는 기존 방식 유지(체크포인트 경로명으로 자동 판별)
   * 체결(Finger Change) 이동 단계 추가 - VLA 데모 시퀀스 맨 앞(home 경유 전)과 맨 뒤(home 복귀 후)에 지정 좌표 이동 3~4단계 추가, UI 체크박스로 on/off
   * STOP 정지 반응성 개선 - home 이동(moveJ)에도 20ms 주기 STOP 감시 워치독(stopJ) 추가
   * use_z_freeze UI 드롭다운화 - false/act/servoing 3모드를 콤보박스로 노출

* 순서 및 단계 요약
   * VLA Demo 클릭 → (Finger Change) 체결 이동 → home 경유 → 사전 티칭 → ACT 추론(그리퍼는 체크포인트별 조건부 계산) → 삽입 시퀀스 → home 복귀 → (Finger Change) 체결 이동 복귀 → home 복귀

* 패키지 구성
   * `experiments/launch_yaml.py` - 체결 이동 단계, move_home watchdog, Finger Change 게이팅
   * `experiments/run_vla.py` - gripper_baseline_from_track, 그리퍼 로깅, 색상 기준 재보정
   * `gello/ui/control_panel.py` - use_z_freeze 드롭다운, Finger Change 체크박스
