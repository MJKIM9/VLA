# 진행 보고 (발표용)

* 기간: 26.07.20 - 26.07.27

* 이번 기간 개발 내용
   * **회전 표현 전환 가능한 state/action 구조** — `URRobot`에 `unwrap_rotvec` 옵션 추가, 체크포인트(v19: RPY / v20: 축각)에 맞춰 state 표현과 액션 회전 델타 계산 방식을 함께 전환하도록 `state_orientation_key()` / `uses_rotvec_action_delta()`로 분기
   * **축각 ±π 불연속 보정** — `_unwrap_rotvec()`으로 UR 축각(rotation vector)이 π 근처에서 부호가 뒤집히는 불연속을 이전 프레임과의 연속성 기준으로 보정
   * **VLA 추론 안전 장치 추가** — 절대 선속도 상한(0.1 m/s, 모든 override 이후 최종 적용), 최소 z 하강 속도 보장(-0.0002 m/step), 추론 시작 시 Δxyz/Δrotvec 연속성 초기화(`reset_delta_tracking`)로 사전 동작 잔여값 유입 차단
   * **서보잉(시각 정렬) 버그 수정 및 튜닝** — y축 부호 반전 버그로 인한 발산 문제 해결, 목표를 완전 일치가 아닌 이미지 높이 3% 오프셋으로 변경, 게인 축소(0.2→0.05)로 반응 완화
   * **오프라인 학습 스크립트 재작성** — `train_act.py`/`train_align.py`를 현재 설치된 lerobot(tyro 기반 CLI)에 맞게 재작성, ACT `n_action_steps`가 `chunk_size` 이하여야 하는 제약 반영
   * **데이터 손실 방지** — lerobot 0-d 배열 통계 버그 몽키패치, Ctrl+C 강제 종료 시에도 recorder를 안전하게 닫는 `active_recorder` 등록 구조, 흩어진 에피소드 병합 스크립트(`merge_episodes.py`) 추가
   * **제어 UI 확장** — 체크포인트/데이터셋 드롭다운 선택, VLA 파라미터 패널, ACT/Align 오프라인 학습 실행 버튼, 한글 폰트(Noto Sans CJK KR) 및 카메라 미리보기 확대

* 순서 및 단계 요약
   * state/action 회전 표현: yaml `unwrap_rotvec` 설정 → `URRobot`이 모드 저장 → 녹화/추론 양쪽에서 동일 기준으로 state 조립 및 액션 델타 계산
   * VLA 추론 루프: 추론 시작 시 델타 추적 리셋 → chunk 액션 획득 → z 게인/최소 하강 적용 → 서보잉 적용(대상 모드일 때) → 최종 속도 상한 클램프 → servoJ 실행

* 패키지 구성
   * `gello/robots/ur.py` — URRobot: unwrap_rotvec 옵션, 축각 불연속 보정, state/action 표현 분기
   * `experiments/run_vla.py` — VLA 추론 루프: 안전 클램프, 서보잉, orientation_key 분기
   * `experiments/launch_yaml.py` — 하이브리드 데모/녹화 진입점, active_recorder 안전 종료, UI 콜백
   * `experiments/train_act.py`, `experiments/train_align.py` — 오프라인 학습 subprocess 실행
   * `experiments/merge_episodes.py` — 에피소드 병합 유틸리티 (신규)
   * `gello/ui/control_panel.py` — 체크포인트/데이터셋/VLA 파라미터/학습 실행 UI
