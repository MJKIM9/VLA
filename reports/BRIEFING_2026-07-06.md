# 진행 보고 (발표용)

* 기간: 26.06.29 - 26.07.06

* 이번 기간 개발 내용
   * **텔레오퍼레이션 제어 루프 및 컨트롤 패널 UI 구축** — launch_yaml.py에서 GELLO→UR10 실시간 제어 루프를 구현하고 Tkinter 기반 컨트롤 패널(gello/ui/control_panel.py)을 개발했다. STOP, E-STOP, Teleop ON/OFF, 데이터 저장, VLA 실행, GoHome 버튼을 제공한다.
   * **LeRobot 형식 데이터 레코더 구현 및 버그 수정** — gello/data_utils/lerobot_recorder.py에서 LeRobotDataset v0.4 래퍼를 구현했다. Parquet 파일 덮어쓰기 버그(`_writer_closed_for_reading=True`)와 에피소드 카운트 표시 오류(기존 데이터셋의 num_episodes 초기화)를 수정했다.
   * **ACT 정책 학습 및 추론 파이프라인 완성** — experiments/run_vla.py에서 ACT 추론 루프를 구현했다. 핵심 버그로 학습 시 preprocessor/postprocessor가 MEAN_STD 정규화를 적용하지만 추론 시 이 과정이 누락되어 joint2가 -10° ~ -20°로 오동작하는 문제를 발견 및 수정했다. 체크포인트의 safetensors에서 통계를 직접 로드해 관찰값 정규화와 액션 역정규화를 적용한다.
   * **DATC 그리퍼 드라이버 및 UR 로봇 개선** — Modbus RTU 기반 DATC 그리퍼 드라이버(gello/robots/datc_gripper.py)를 구현했다. UR 제어에 max_delta 클리핑([0.030, 0.030, 0.030, 0.030, 0.060, 0.060] rad/스텝)을 추가해 급격한 동작을 방지하고, 실제 관절속도와 TCP 데이터를 관찰값에 포함했다.
   * **중력 보상 구현** — gello/robots/gravity_comp.py에서 MuJoCo forward kinematics로 중력 토크를 계산하고 Dynamixel PWM 제어 모드로 인가한다. driver.py에 PWM 제어 모드(set_pwm), set_operating_mode() 스레드 안전 처리를 추가했다.
   * **2π 오프셋 자동 보정** — 시작 시 GELLO와 UR 관절각 차이가 2π 배수이면 joint_offsets를 자동 보정하고 YAML에 저장한다.

* 순서 및 단계 요약
   * 시스템 초기화(YAML 로드, 로봇 및 에이전트 생성) → 2π 자동 보정 → 데이터셋 준비 및 카메라 초기화 → 제어 루프 및 레코드 워커 스레드 시작 → UI 실행
   * 텔레오퍼레이션 ON → GELLO 값 읽기 → UR 전달 및 프레임 기록 → Save로 에피소드 확정
   * VLA 시작 → HOME 이동 → 관찰값 정규화 → ACT 추론 → 액션 역정규화 → UR 전달

* 패키지 구성
   * `experiments/`: launch_yaml.py(메인), run_vla.py(VLA 추론), train_act.py(학습)
   * `gello/ui/`: control_panel.py (Tkinter 컨트롤 패널)
   * `gello/data_utils/`: lerobot_recorder.py (LeRobot 데이터 저장)
   * `gello/robots/`: ur.py, datc_gripper.py, gravity_comp.py
   * `gello/dynamixel/`: driver.py (PWM 모드 추가)
   * `gello/zmq_core/`: robot_node.py (ZMQ 안정성 개선)
   * `configs/`: ur10_gello.yaml (캘리브레이션, VLA 체크포인트 등 전체 설정)
