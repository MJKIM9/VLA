# 진행 보고 (발표용)

* 기간: 26.07.09 - 26.07.16

* 이번 기간 개발 내용
   * **Delta Action 전환** — 절대 관절각 대신 GELLO_t - UR_t 차분값을 action으로 기록 및 추론 적용. 추론 시 `action = q_current + delta_np`로 실행하여 시작 자세 의존성 감소
   * **State 입력 xyz 오정렬 벡터 확장** — 손목 카메라 HSV 검출로 빨간 그리퍼-노란 물체 3D 좌표 차이 벡터(red_xyz - yellow_xyz) 계산, STATE_DIM 16→17차원으로 확장
   * **하이브리드 데모 구조 도입** — 6단계 사전 티칭(그리퍼 제어, 파지 전/파지/파지 후 자세, 홈 복귀) 수행 후 VLA 추론 시작하는 2단계 구조 구현
   * **카르테시안 직선 이동(moveL) 전환** — 사전 티칭 관절 공간 보간(move_to)을 moveL로 교체. 매 이동 전 reuploadScript()로 RTDE 스크립트 재시작, 정지 감지용 watchdog 스레드 포함
   * **Temporal Ensembling 및 스무딩 시도 및 롤백** — 청크 경계 튀는 현상 개선 시도(Temporal Ensembling, dx/dy 이동평균), 동작 품질 저하로 모두 롤백

* 순서 및 단계 요약
   * 데이터 수집: GELLO 텔레오퍼레이션 → delta action 계산 → align_xyz 계산 → LeRobot HDF5 저장
   * 하이브리드 데모: servoStop → reuploadScript → 사전 티칭 6단계(moveL) → VLA 추론 루프
   * VLA 추론: 카메라 백그라운드 버퍼 준비 → 워밍업 chunk → 루프(카메라 읽기 → delta 꺼내기 → servoJ 실행 → 비동기 다음 chunk prefetch)

* 패키지 구성
   * `experiments/launch_yaml.py` — 메인 진입점, 하이브리드 데모, 제어 루프, 데이터 수집 통합
   * `experiments/run_vla.py` — VLA 추론 루프, ACTPolicy 실행, 카메라 버퍼, delta action
   * `configs/ur10_gello.yaml` — checkpoint 경로, chunk_size, speed_scale 설정
   * `gello/cameras/realsense_camera.py` — pixel_to_3d() 깊이 좌표 변환
