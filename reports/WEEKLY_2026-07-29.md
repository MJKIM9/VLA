## 1. 이번 기간 요약

v21(축각 대신 RPY 방식, 그리퍼 실제 명령값으로 학습된) 체크포인트에서만 추론 시 그리퍼 기준값을 실제 명령값 기준으로 계산하도록 조건부 처리했다. VLA 데모 하이브리드 시퀀스의 맨 앞과 맨 뒤에 체결(Finger Change) 이동 단계를 추가하고 UI 토글로 켜고 끌 수 있게 했으며, home 이동(moveJ)에도 STOP 감시(watchdog)를 추가해 정지 반응성을 높였다. `use_z_freeze` 3가지 모드를 UI 드롭다운으로 노출했다.

## 2. 개발 내용 상세

### 원리

**그리퍼 기준값의 체크포인트별 조건부 적용**: DATC 그리퍼는 위치 피드백이 없어 로봇 관측값(`obs["gripper_position"]`)이 항상 0으로 고정된다. v19는 학습 데이터 자체가 이 값을 항상 0으로 기록해 왔기 때문에 추론 시에도 0을 그대로 넣는 것이 학습 분포와 일치한다. 반면 v21은 자동 녹화 로직이 실제로 하드웨어에 보낸 마지막 명령값을 state/action에 기록하도록 만들어져 있어(선행 세션 작업), 추론 시에도 실제 명령값을 기준으로 그리퍼 목표치를 누적해야 학습-추론 분포가 일치한다. 이를 위해 `run_inference()`에 `gripper_baseline_from_track` 파라미터를 추가하고, 현재 로드된 체크포인트 경로 문자열에 "v21"이 포함되는지로 자동 판별해 v19 실행에는 영향을 주지 않도록 했다.

**체결(Finger Change) 이동 단계**: VLA Demo 버튼을 눌렀을 때 기존 하이브리드 시퀀스(사전 티칭 → ACT 추론 → 삽입 → home 복귀)의 맨 앞(홈 경유 전)과 맨 뒤(홈 복귀 후)에 지정된 카테시안 좌표로 이동하는 단계를 추가했다. UI의 "Finger Change" 체크박스로 이 구간 전체(7개 이동)를 포함할지 뺄지 제어한다.

**STOP 정지 반응성 개선**: 기존에는 `move_cs`(moveL)와 `move_z_fixed_rp`(moveL)에만 20ms 주기로 정지 신호를 감시하다 즉시 `stopL`을 호출하는 워치독 스레드가 있었고, `move_home`(moveJ)에는 이동 시작 전 확인만 있고 이동 중 감시가 없었다. 이번에 `move_home`에도 동일한 방식의 워치독(단, 관절 이동이므로 `stopJ` 호출)을 추가했다.

**use_z_freeze UI화**: 기존에는 `configs/ur10_gello.yaml`을 직접 수정해야 `false`/`"act"`/`"servoing"` 세 모드를 바꿀 수 있었는데, VLA Parameters 패널에 콤보박스를 추가해 실행 중 바로 선택하고 "Apply Parameters"로 반영할 수 있게 했다.

### 구성

- `experiments/run_vla.py`
  - `run_inference()`에 `gripper_baseline_from_track: bool` 파라미터 추가, 그리퍼 목표값 계산 시 조건에 따라 `q_current[6]`(기존, 항상 0) 또는 추적값(`_last_gripper_t`) 중 하나를 기준으로 사용
  - 그리퍼 명령 계산 시 매 스텝 `[VLA][gripper] baseline_mode=... cur=... act_delta=... -> t=... raw=...` 로그 추가, 추론 시작 시 모드 요약 로그 추가
  - 노란색 검출 HSV 하한/상한 값 재보정(`[10, 150, 120]`~`[26, 255, 255]`), 기존 값은 주석으로 보존
  - `_y_ok`(삽입 y 정렬 임계값), `_SERVOING_K`(서보잉 비례 게인) 값 조정
- `experiments/launch_yaml.py`
  - `vla_demo_fn` 0단계(체결 전/자세/후 이동, home 경유 전)와 5단계(체결 후/자세/전 이동, home 복귀 후) 신설, 둘 다 `vla_cfg.get("finger_change", True)`로 게이팅
  - `move_home`에 STOP 워치독(`stopJ`) 추가, `set_gripper()`에 `wait` 파라미터 추가(그리퍼 open 직후 불필요한 1.5초 대기 제거)
  - 파지 전/파지/파지 후 이동, home 이동, 삽입 후 복귀 이동의 속도/가속도 값 조정
  - `_gripper_baseline_from_track = "v21" in str(_vla_checkpoint[0]).lower()` 판별 로직 추가
- `gello/ui/control_panel.py`
  - `_VLA_CHOICE_PARAMS`(콤보박스 파라미터 목록) 신설, `use_z_freeze` 드롭다운(false/act/servoing) 추가
  - `_VLA_BOOL_PARAMS`에 `finger_change`(표시 라벨 "Finger Change") 추가, 체크박스 표시 라벨을 값과 분리해 관리하도록 구조 변경
- `gello/robots/ur.py`: 소규모 정리

### 순서 및 단계

1. VLA Demo 버튼 클릭
2. (Finger Change 켜짐) 0단계: 체결 전 → 체결 자세 → 체결 후 이동
3. 1단계: home 경유 → 사전 티칭(그리퍼 open/파지/close)
4. 2단계: ACT 추론 — 체크포인트가 v21이면 그리퍼 목표값을 실제 명령값 추적 기준으로, 그 외에는 기존 방식으로 계산
5. 3단계: 삽입 시퀀스(조건 충족 시)
6. 4단계: home 복귀
7. (Finger Change 켜짐) 5단계: 체결 후 → 체결 자세 → 체결 전 이동 → home 복귀
8. 이동 중 STOP 시: `move_cs`/`move_home`/`move_z_fixed_rp` 각각의 워치독이 20ms 이내 감지해 `stopL`/`stopJ` 호출
