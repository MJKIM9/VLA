## 1. 이번 기간 요약

UR10 슬레이브 로봇과 GELLO 마스터 디바이스를 연결하는 텔레오퍼레이션 시스템을 개발하고, 수집한 시연 데이터로 ACT(Action Chunking with Transformers) 정책을 학습 및 추론하는 전체 파이프라인을 구축했다. 이번 기간에는 Tkinter 기반 컨트롤 패널 UI, LeRobot 형식 데이터 레코더, DATC 그리퍼 드라이버, MuJoCo 기반 중력 보상, VLA 추론 파이프라인의 정규화 버그 수정이 완료됐다.

## 2. 개발 내용 상세

### 원리

**텔레오퍼레이션 파이프라인**
- GELLO(Dynamixel 기반 마스터 디바이스)의 관절각을 읽어 UR10 슬레이브 로봇에 실시간 전달한다.
- GelloAgent.act()에서 `joint_offsets`와 `joint_signs`를 적용해 Dynamixel raw 값을 UR 호환 관절각(rad)으로 변환한다.
- ZMQ 소켓(REQ-REP 패턴)을 통해 로봇 명령을 프로세스 간 전달하며, ZMQServerRobot과 ZMQClientRobot이 쌍을 이룬다.
- UR 제어는 `servoJ` 명령을 사용하며 스텝당 최대 변화량(max_delta: [0.030, 0.030, 0.030, 0.030, 0.060, 0.060] rad)을 클리핑해 급격한 동작을 방지한다.

**데이터 수집 및 저장**
- LeRobotDataset(v0.4) 형식으로 데이터를 저장한다. 각 프레임에 `observation.state`(14차원: 관절위치 7, 관절속도 6, 그리퍼 1), `action`(7차원), 카메라 영상(exterior, wrist)이 기록된다.
- Parquet 파일 덮어쓰기 버그는 `_writer_closed_for_reading = True`를 설정해 각 에피소드를 별도 파일(file-000.parquet, file-001.parquet…)에 기록함으로써 해결했다.
- 카메라 읽기와 add_frame은 별도 스레드(record_worker)에서 큐(Queue) 방식으로 처리해 제어 루프 지연을 방지한다.

**ACT 정책 학습 및 추론**
- LeRobot lerobot_train.py를 사용해 ACT 정책을 학습한다. 학습 시 preprocessor가 관찰값과 액션을 MEAN_STD 정규화한 뒤 모델에 입력하고, postprocessor가 출력을 역정규화한다.
- 추론 시 `ACTPolicy.from_pretrained()`은 이 processor를 포함하지 않으므로, 체크포인트의 safetensors 파일에서 정규화 통계를 직접 불러와 관찰값 정규화 및 액션 역정규화를 적용하도록 수정했다.
- 이 버그가 수정되기 전에는 정규화 공간의 출력값(~0)이 그대로 UR로 전달되어 joint2가 -10° ~ -20°로 향하는 오동작이 발생했다. 수정 후 joint2의 학습 평균(-108.5°) 근방으로 정상 복귀했다.

**중력 보상(Gravity Compensation)**
- MuJoCo forward kinematics를 이용해 각 관절의 중력 토크를 계산한다.
- Dynamixel PWM 제어 모드(PWM_CONTROL_MODE = 16)로 전환한 뒤, 토크를 PWM 값으로 변환해 각 서보에 인가한다.
- `set_operating_mode()` 호출 시 백그라운드 읽기 스레드를 중지 후 모드 변경, 재시작하는 로직을 추가해 버스 충돌을 방지했다.

**DATC 그리퍼 드라이버**
- Modbus RTU 프로토콜(FC06/FC16)로 DATC 그리퍼를 제어한다. CRC16 체크섬을 직접 계산해 시리얼 포트로 전송한다.
- 초기화, 열기, 닫기, 위치 제어, 임피던스 모드 등의 명령을 지원한다.
- UR 로봇에 그리퍼 포지션 명령 시 별도 스레드로 비동기 전송해 servoJ 타이밍에 영향을 주지 않는다.

**2π 오프셋 자동 보정**
- 시작 시 GELLO 관절각과 UR 관절각의 차이가 2π의 배수이면 joint_offsets를 자동 보정하고 YAML 파일에 저장한다. 이 기능은 Dynamixel 재시작 후 초기 위치 불일치를 방지한다.

### 순서 및 단계

1. **시스템 초기화**: `launch_yaml.py` 진입 → YAML 설정 로드 → UR 로봇 및 GELLO 에이전트 인스턴스 생성 → ZMQ 서버 시작
2. **2π 자동 보정**: GELLO와 UR 관절각 비교 → 2π 배수 오프셋 검출 시 YAML 업데이트
3. **데이터셋 준비**: `make_lerobot_dataset()`로 기존 데이터셋 로드 또는 신규 생성 → `LeRobotRecorder` 래퍼 초기화 → RealSense 카메라 초기화
4. **제어 루프 시작**: `control_loop_with_record()` 별도 스레드에서 실행 → `record_worker()` 스레드 시작 (큐 기반 비동기 저장)
5. **UI 실행**: `ControlPanel` 생성 → Tkinter 메인 루프
6. **텔레오퍼레이션**: UI에서 Teleop ON → `teleop_event.set()` → 제어 루프가 GELLO 값을 읽어 UR에 전달 → 프레임 기록
7. **에피소드 저장**: UI에서 Save → `recorder.end_episode()` → `save_episode()` → `_writer_closed_for_reading = True`로 파일 완성
8. **VLA 추론**: UI에서 VLA 시작 → HOME 위치 이동 → `load_policy()`로 모델 및 정규화 통계 로드 → `run_inference()` 루프 (정규화→추론→역정규화→UR 전달)
9. **학습**: `lerobot_train.py`로 ACT 학습 (20k 스텝, chunk_size=30, 52M 파라미터, 최종 loss 0.060)
